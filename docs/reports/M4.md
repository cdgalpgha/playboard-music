# Milestone 4 report: MIDI and MusicXML import, chart generation

## What works

- **MIDI parser** (`formats/midi-file.ts`): formats 0, 1 and 2, PPQ and SMPTE
  timing, running status, multi-byte delta times, sysex and meta events
  (tempo, time and key signature, track names), FIFO pairing of overlapping
  notes, hanging notes closed at track end, drum channel excluded.
- **Chart generation**: MIDI tracks become right/left hand by pitch (or split
  at middle C for one track), measures from time signatures, tempo map from
  tempo events; MusicXML and compressed `.mxl` go through the existing
  parser. Both produce a raw beat-based score that edits are applied to.
- **Edits**: transpose ±12 semitones (key signature follows; out-of-range notes
  wrap by octaves), tempo 25–200%, per-track hand assignment or exclusion,
  title and composer. Re-editable later from the library.
- **Import page**: drag-and-drop or file picker, live preview of notes per
  hand, measures, length and range, save to a private library; library list
  with practise, edit and delete. Imported songs open in the same practice
  page as built-in pieces, with sheet music (transposed) for MusicXML.
- **MIDI export** of free-play recordings.

## Measured numbers

| What | Result |
|---|---|
| Dense imported score (1,920 notes: 16th-note thirds + 4-note chords every eighth) in Listen mode | 60.0 fps, p95 frame 16.7 ms, 0 dropped, canvas draw p95 0.3 ms |
| Import of a two-track MIDI file to preview (headless Chromium) | under 100 ms |

## Tests

- Vitest: 89 unit tests (adds 10 MIDI parser/conversion tests and 4 transform
  tests).
- Playwright: 16 end-to-end tests, adding MIDI import with key/tempo/hand edits
  verified in the resulting chart, `.mxl` import with sheet music, an
  unreadable-file message, and the dense-score frame rate.

## Known issues

- MIDI imports have no sheet music (see M3 known issues).
- MIDI files without track separation for the hands (one track, both hands)
  are split at middle C, which is wrong for crossing hands; the player can
  only reassign whole tracks, not individual notes.
- Tempo edits apply one factor to the whole piece; there is no per-section
  tempo editing.

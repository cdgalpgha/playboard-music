# M7 report: progress, accounts and sync, offline, accessibility, Lighthouse

## What was built

- **Progress page** (`/progress`): streak, a daily goal (default 10 minutes,
  adjustable), practice minutes for the last 14 days, accuracy and timing
  trends per skill, and recent sessions. Everything is computed from stored
  sessions (`src/core/progress-math.ts`, D49).
- **Optional cloud sync**: Supabase magic-link sign-in. Settings, user songs,
  sync maps, sessions and lesson progress sync through one `playboard_records`
  table with row-level security (`supabase/schema.sql`). Merge is
  last-writer-wins per record with tombstones (`src/storage/sync/merge.ts`,
  D51). Device-specific settings (YouTube key, sample tier, MIDI device) stay
  local. The build ships with sync **off**. Settings says so and names the two
  environment variables that turn it on (D50).
- **PWA**: `vite-plugin-pwa` with a manifest and SVG icon. The service worker
  precaches 54 files (4.5 MB): the app shell, lessons, pieces and the Basic Pitch
  model. Piano samples are not precached because they already live in IndexedDB
  per tier (D52). The service worker is registered in production builds only.
- **Accessibility**: the muted text colour is darkened from #7d877a to #646e61,
  which brings small labels above 4.5:1 contrast. The sign-in form has a label
  and live status text. robots.txt is added.
- **Home** lists the features from every milestone.

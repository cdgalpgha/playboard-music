# Milestone 3 report: sheet music, lesson format, ten lessons

## What works

- **Sheet view** (`ui/sheet/SheetView.tsx`): OpenSheetMusicDisplay renders the
  MusicXML (key and time signatures, fingering, dynamics, beaming), loaded
  lazily. The current measure is highlighted from OSMD's layout boxes and
  scrolled into view (instantly with reduced motion). Clicking a measure jumps
  playback there. Re-layout on width change.
- **Lesson format**: each lesson is JSON metadata (unit, goals, steps, practice
  presets, pass mark, license) plus a MusicXML score. Sources live in
  `content/lessons.ts`; `npm run build:content` writes
  `public/content/lessons/*.musicxml` and `src/content/builtin/lessons.json`,
  checking that every score parses and contains the hands the lesson practises.
- **Ten lessons** across six units: Meet middle C, Five fingers in C position,
  The left hand joins, Whole/half/quarter notes (Hot Cross Buns), Mary Had a
  Little Lamb, Ode to Joy right hand, Hands together (Lightly Row), The C major
  scale (thumb under), First chords C/F/G, Minuet in G hands together. Steps
  include key diagrams with finger numbers.
- **Learn path page** with per-lesson completion, best score and the
  recommended next lesson; **lesson page** with goals, steps, sheet music above
  the falling notes, presets applied, and a pass/fail result that links to the
  next lesson. Progress is stored in IndexedDB.
- Piece pages now show the sheet music too (toggleable).

## Tests

- Vitest: 75 unit tests (unchanged in count; content correctness is checked
  by the content build).
- Playwright: 12 end-to-end tests, adding a full lesson played via mock MIDI
  (sheet engraved, highlight advances, completion recorded and shown on the
  path) and a load check of all ten lesson pages.

## Known issues

- Sheet music is shown only for MusicXML sources. Imported MIDI files
  (milestone 4) get falling notes only; turning MIDI into readable notation
  needs quantization and voice separation, which is out of scope.
- The highlight marks the whole measure, not the current note.
- Lesson text is English only.
